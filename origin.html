A STAR gives direction.
A TARGET gives position.

Before a target can be named,
its origin must first be found.

No place name is stored here.
Only four fragments remain.

01 // SIGHT

Four observers surround the origin.

One receives the first light.

One keeps its eye on the star
that appears never to move.

One stands beneath the sun
when it reaches the highest point of its daily arc.

One remains until the final light disappears.

Give each observer the single English word
that defines the direction it faces.

Arrange all four words
as a machine would sort text.

From the second entry,
retain only its first character.

02 // TARGET ARRAY

The name of this system contains seven positions.

S T A R G E T

A valid lock state requires
exactly three different positions to be active.

The order in which they are activated
does not matter.

A state containing positions 1, 3, 5
is identical to 5, 1, 3.

No position may be used twice
within the same state.

Determine the total number
of unique valid states.

Retain the result.

03 // AXIS

Return to the four observers.

Do not change their names.

Do not change the sorting rule.

This time, take the first character
of the first entry.

Retain it.

04 // RANGE

Begin with the positive integers.

Discard 1.

Discard every value that can be divided evenly
by any positive integer
other than 1 and itself.

Arrange everything that survives
from smallest to largest.

The first survivor is numbered 01.

Continue until the counter reaches:

100010₂

Do not retain the counter.

Retain the value standing at that position.

FINAL // ACQUISITION

Four fragments have now been recovered.

Reconstruct them in the following order:

DIRECTION / STATE / DIRECTION / RANGE

Encode the result as:

L##-L###

No spaces.
No additional symbols.
